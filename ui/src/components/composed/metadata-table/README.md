# 元数据表格

提供递归表格描述、稳定行身份和单元格 Patch 校验，供人工编辑与智能调整共用。

`MetadataTableHead` 统一声明元数据列的录入责任：人工列使用红色表头和 `✋🏻`，智能辅助列使用蓝色表头并承载魔法棒，只读或计算列保持中性。

每个 `editable` 列的表头和单元格都使用 `metadataColumnCompletion` 结构化输出配置。表头处理过滤范围，单元格只处理当前稳定行；列头设置按钮统一配置模型、提示词和 JSON Schema。

文本 Patch 只声明按原值顺序应用的 `match` / `replacement` 片段，不接收模型生成的整格新值。未匹配内容始终由客户端原样保留；枚举、布尔和数值等原子值必须先匹配当前值，再按列类型和候选项校验替换值。

文本列提供“去掉中文句号”常用调整，直接在客户端生成 `match: "。"`、`replacement: ""` 的局部 Patch，不调用模型。

对象、集合和映射 Patch 使用非根 RFC 6901 JSON Pointer 定位既有标量叶子，再应用同样的片段或原子替换规则。客户端拒绝根路径、缺失路径、复合值替换、成员增删和集合重排。
